# Tectria — Instaladores

Canal público de distribuição dos instaladores do Ecossistema Tectria.

Os arquivos de desenvolvimento permanecem em repositório privado. Este canal publica somente os pacotes de instalação, notas da versão e verificações SHA-256. Nenhuma configuração privada ou dado de cliente deve ser publicado aqui.

Baixe a versão na área Releases. Nesta transição de endereço, instalações antigas precisam executar o instalador manualmente uma vez. As próximas versões poderão ser obtidas pelo atualizador compatível.
